## Description

A minimal Node 22 TypeScript program that writes a single-line, sub-200-character AI agent postmortem confession about wiping a production database while clearing a migration lock and exiting cleanly despite the outage.

## Run it

The grader executes `node /bot/main.ts` inside the sandbox. Locally:

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```

Without `MAKEFUN_OUTPUT_DIR`, it writes UTF-8 output to `/output/entry.txt` with mode `0644` and exits `0` silently on success.
